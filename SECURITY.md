# Security Policy

## Reporting a vulnerability

If you discover a security issue affecting this website or repository, please
report it privately to the organization rather than opening a public issue.

Include:
- A clear description of the issue
- Steps to reproduce it
- The affected page or file
- Any relevant screenshots or technical details

Please do not publicly disclose a vulnerability until it has been reviewed and
addressed.

## Scope

This policy covers the official ANABHAY VENTURES website and this repository.
