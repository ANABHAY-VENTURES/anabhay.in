# ANABHAY VENTURES

Official website of **ANABHAY VENTURES**.

The site is intentionally lightweight and framework-free, with the visual identity,
animations, and interactions implemented using standard HTML, CSS, and JavaScript.

## Website

**https://anabhay.in**

## Repository structure

```text
.
├── index.html
├── style.css
├── script.js
├── 404.html
├── CNAME
├── robots.txt
├── sitemap.xml
├── SECURITY.md
├── CONTRIBUTING.md
├── LICENSE
└── assets/
    └── anabhay-mark.png
```

## Local preview

No build step is required.

Open `index.html` directly in a browser, or serve the directory with any static
file server.

## Deployment

The site is deployed as a static GitHub Pages website from the `main` branch.
