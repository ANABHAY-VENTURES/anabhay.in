# Contributing

This repository contains the official ANABHAY VENTURES website.

The website and brand are maintained by ANABHAY VENTURES. External pull requests
are not required for normal website operation.

If you believe a correction is necessary, please open an issue with:
- A concise description
- The relevant page or file
- The proposed correction
- Supporting information where applicable

Please do not submit third-party assets, copied branding, or material for which
you do not have the necessary rights.
